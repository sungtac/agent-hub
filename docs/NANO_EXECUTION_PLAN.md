# 나노 단위 실행 기준

모든 항목은 구현, 오류·회귀 검토, 검증을 마친 뒤에만 완료로 기록한다. 현재 단계별 상태와 근거는 `IMPLEMENTATION_STATUS.md`를 정본으로 삼는다. 아래 표는 승인 기준의 원래 순서이며, 이미 구현된 공급자 항목은 현재 상태에 맞춰 통합했다.

| 순서 | 관찰 가능한 단위 | 산출물 | 검증 | 실패 시 처리 |
|---|---|---|---|---|
| 0.1 | 환경 상태를 읽기 전용으로 수집 | 버전 있는 환경 보고서 | 알려진 Codex·Python 상태와 일치 | 누락 도구를 `unknown`으로 보고하고 중단 |
| 0.2 | 호환성·의존성 계약 검사 | 잠금 전 검증 결과 | 지원/조건부/미검증 분류 일치 | 설치하지 않고 차이를 등록 |
| 1.1 | 런타임 데이터 경계 생성 | 설정 스키마와 무시 규칙 | 코드·비밀·사용자 데이터가 분리됨 | 생성물 제거 또는 격리 |
| 1.2 | 새 환경 초기화 검사 | 초기화 시험 | 전역 공급자 설정 불변 | 변경이 감지되면 복구 후 실패 |
| 2.1 | 작업 원장에 작업 생성 | 버전 있는 작업 기록 | 재실행해도 중복 없음 | 원장 기록을 무효화하지 않고 실패 이벤트 추가 |
| 2.2 | lease와 승인 기록 | 전환 가능한 상태 | 동시 갱신 충돌이 거절됨 | lease 만료·복구 절차 수행 |
| 3.1 | Codex 능력 사전검사 | 정규화된 capability 결과 | 비밀값 없이 결과 생성 | `unknown` 상태로 격하 |
| 3.2 | Codex 작업 실행·취소 | 정규화된 결과·오류 | 성공·실패·취소 경로 통과 | 원장에 복구 가능한 실패 기록 |
| 4.1 | 파일 전수 목록 생성 | Coverage Manifest | 모든 발견 파일이 상태를 가짐 | 접근 실패 파일을 명시적으로 보류 |
| 5.1 | LangGraph 승인 중단·재개 | 멱등 영수증 | 재개 때 물질적 동작이 중복되지 않음 | 안전하게 재시도 가능 상태 유지 |
| 6.1 | 기존 스킬 등록 | Skill Registry 항목 | 복사 없이 기존 경로·호환성 확인 | `unavailable`로 등록 |
| 6.2 | Loadout 렌더링 | 공급자별 생성 설정 | 원본 사용자 설정 불변 | 생성물을 폐기 |
| 7.1 | 범위 접근 거부 | 권한 시험 결과 | company/personal 교차 접근 거절 | 이벤트 기록 후 차단 |
| 7.2 | 삭제 전파 | 삭제 영수증 | 원본·색인·캐시 상태가 추적됨 | 미완료 위치를 보류로 유지 |
| 8.1 | Claude 어댑터·공급자 선택 | 계약 시험 결과 | 준비된 공급자만 선택하고 Codex↔Claude handoff 통과 | 완료: 동일 원장 실호출 및 제한 시 즉시 handoff 시험 통과 |
| 8.2 | Antigravity 어댑터 | 실제 CLI 계약 시험 | Codex·Claude·Antigravity 세 공급자의 원장 기반 handoff 통과 | 완료: 동일 원장 실호출 시험 통과 |
| 9.1 | LangMem 후보 기억 격리 | 후보 평가 결과 | 승인 전 운영 지식그물과 행동 규칙에 노출되지 않음 | 완료: 격리·중복·승인/거절·재시작 시험 통과; 실제 모델 추출 운영은 남음 |
| 9.2 | DeepAgents 권한 경계 | 스킬·파일 권한 결과 | 하네스 승인·경로 경계 밖 작업 불가 | 완료: registry/scope 검증, 읽기 전용 메인 도구, 서브에이전트 write deny, shell 미지원 시험 통과 |
| 10.1 | 자동개선 샌드박스 | 기준선 비교·롤백 기록 | 개선 실패 시 자동 복구 및 반복 중단 | 완료: bwrap 격리·테스트·백업·rollback·cooldown·한 번에 한 후보 observer/CLI와 관리형 cron scheduler 구현·활성화 |
| 12.1 | 재시작·절전·제한 복구·전체 점검 | 운영 복구 보고서 | 데이터 손실·중복 동작 없음, 전수 리뷰 종료 | 완료: backup 복원·재시작 lease 복구·제한/네트워크 handoff·profile 경계·최종 리뷰와 매니페스트 검증 |
