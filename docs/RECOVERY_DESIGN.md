# 복구 설계 기준

이 문서는 복구 구현 전의 최소 계약이다. 실제 암호화 키와 백업은 아직 만들지 않는다.

## 복구 대상과 정본

| 대상 | 정본 | 복구 방법 | 현재 상태 |
|---|---|---|---|
| 하네스 코드·정책 | Git 저장소 | 검증된 커밋에서 복원 | 초기 기준선 미커밋 |
| Hub 설정 | `config/hub.json` | 암호화 백업에서 복원 | 로컬 구성만 생성됨 |
| 작업 원장 | 향후 `runtime/tasks` | 원장 백업과 이벤트 재생 | 미구현 |
| 지식·기억 | 향후 `runtime/knowledge` | 범위별 백업·삭제 영수증 확인 | 미구현 |
| 검색 색인·체크포인트 | 재생성 가능한 캐시 | 원장에서 재생성 | 미구현 |

## 구현 불변 조건

- 복구는 원장·원본을 우선하고 색인·캐시를 뒤에서 재생성한다.
- 비밀값, 공급자 인증 정보, 암호화 키는 코드 저장소와 로그에 기록하지 않는다.
- 백업·복구·삭제 전파는 실제로 구현된 뒤 장애·재시작 시험을 통과해야 지원으로 선언한다.
- 복구 실패는 원본을 덮어쓰지 않고, 새 복구 작업 기록과 원인만 남긴다.
